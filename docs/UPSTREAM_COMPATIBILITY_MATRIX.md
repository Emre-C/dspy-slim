# Upstream Compatibility Matrix

This is the living stable-release audit matrix for keeping `dspy-slim` behaviorally faithful to upstream DSPy on its supported surface.

Use this file as the working checklist before changing user-visible behavior and before preparing upstream issues or PRs from local findings.

## Audit Status

- Upstream stable references refreshed in `../tmp/`: `stanfordnlp/dspy` `3.2.0` (`d3a890c0`) and `gepa-ai/gepa` `v0.1.1`, verified directly for the surfaces below
- Local reference: this checkout as of 2026-04-24
- Scope of this refresh pass: the kept `dspy-slim` boundaries (`Predict`, `ChainOfThought`, `ReAct`, `Parallel`, `RLM`, `GEPA`, `BetterTogether`, `LM`, `BaseLM`) plus the supporting adapters, cache, signatures, and repo docs that define those surfaces
- This matrix remains the current stable-release compatibility artifact; post-`3.2.0` `main`-branch mergeability work is tracked separately in [`UPSTREAM_FORWARD_COMPATIBILITY.md`](UPSTREAM_FORWARD_COMPATIBILITY.md)
- The older `3.1.3` audit bundle in this directory is still useful as historical context, but it is no longer the current compatibility anchor
